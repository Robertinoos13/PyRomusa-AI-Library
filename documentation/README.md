# Welcome to `PyRomusa AI` documentation 📃🎉

Here you can find explanations for each function available in objects such as `Chatbot()` or `RealChatbot()`.

As of October 2026, this is the only official documentation, added directly to the official `PyRomusa AI` repository from GitHub.

This documentation doesn't contain many practical examples showing how `PyRomusa AI` is used in practice, but you can check the [`tutorials/code examples/` folder](https://github.com/Robertinoos13/PyRomusa-AI-Library/tree/main/tutorials/code%20examples) to see real, complete examples.

---

## How do you extract exactly what you need from the documentation?

In the `📁 documentation/` folder, the `.md` files are organized exactly as they can be accessed from the `pyromusa_ai` framework while coding. 

For example, if I am interested in details about the `bot.helper.how_to_start()` function within the `Chatbot()` object, I navigate to the path `documentation/Chatbot()/Help/how_to_start().md` from this repo.

If you want specific details about a particular object (e.g., `Chatbot()`, `Help()`, `Trainer()`, `Storage()`, etc.), locate the folder named after it and access the `📄README.md` file inside.
