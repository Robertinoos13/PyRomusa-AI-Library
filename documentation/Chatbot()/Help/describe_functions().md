# `bot.helper.describe_functions()`

## Description

Displays a table (DataFrame) listing some basic `PyRomusa AI` functions along with brief descriptions. This is a useful function if you want to quickly see which functions are available in `PyRomusa AI` (particularly for the `Chatbot()` object).

## Parameters

no parameters required

## Returns

- **value type(s):** string
- **number of values returned per call:** ???
- **It needs an additional `print()` function:** no

## Codes examples

``` python
from pyromusa_ai import Chatbot

bot = Chatbot()

bot.helper.describe_functions()
```
