# `bot.show_basic_specs()`

## Description

It displays a detailed report covering every possible aspect of the chatbot—from its identity and specifications to training details and the dataset. This is useful if you are not yet familiar with the specific details of the chatbot.

## Parameters

no parameters required

## Returns

- **value type(s):** string
- **number of values returned per call:** ???
- **It needs an additional `print()` function:** no

## Codes examples

``` python
from pyromusa_ai import RealChatbot

bot = RealChatbot()

# Here’s what a chatbot looks like with factory settings.
bot.show_basic_specs()
```
