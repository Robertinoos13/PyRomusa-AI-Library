# Contributing to PyRomusa AI 🚀

Thanks for your interest in contributing!

## How to contribute

### 1. Fork the repository
Create your own copy of the repo.

### 2. Make changes
- Improve code
- Fix bugs
- Add features
- Improve documentation

### 3. Test your changes
Make sure nothing breaks.

### 4. Create a Pull Request
Explain clearly:
- What you changed
- Why you changed it

## Guidelines
- Keep code simple (this project is about simplicity)
- Follow the existing style
- Avoid unnecessary complexity

## Ideas you can work on
- New datasets
- Performance improvements
- Better response logic

## Questions?
Open an issue 😄
