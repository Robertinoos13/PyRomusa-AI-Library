## 1. Open your terminal/CMD/bash

Since `PyRomusa AI` is available on PyPI as of September 2026, it can be easily installed via `pip install ...`. To do this, you need to open your terminal:

1. Press the key combination `Win + R`.

2. Type "cmd" and press `Enter`.

3. Write & Run this command:

    ```
    pip install pyromusa-ai
    ```
