# Welcome to MODDED versions 👥🔧

Here you will find custom variations of `PyRomusa AI` made by the community. **If you have an idea to add something new (even something small) to `PyRomusa AI`, then post your variation in this folder.**

## By the way 

Where you see the emoji '🔴' on `📄README.md` file from example `MODDED` project (named `📁PyRomusa_AI-modded-v001-USERNAME`), it must be modified by the owner of the respective version in `MODDED`

## Main rules

- You can freely modify the `PyRomusa AI` code, as long as it's your code and located in the `📁MODDED versions` folder.

- You are not allowed to post versions that steal personal data or other type of danger.

- Your version must be related to `PyRomusa AI`'s goal: to create chatbots

- Your `MODDED` version must reference an official version (e.g. `STABLE v0.10.0`, `EXPERIMENTAL v002`, etc.)

- You are not allowed to modify other developers' versions other than your own.

- You can modify your own version as many times as you want, without increasing the version number (e.g. `modded-v001 -> modded-v002 -> modded-v003` is not supported for the same user/variant)

- If you want to publish multiple versions in the `MODDED` versions folder, it is allowed, provided that the versions change in ascending order, depending on which versions currently exist _(e.g. you released the `modded-v002` version some time ago, and now you want to post another one. If the largest version is `modded-v013`, then continue with `modded-v014`)_
