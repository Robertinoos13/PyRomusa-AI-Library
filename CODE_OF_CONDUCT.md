# Code of Conduct 🤝

## Our Goal
PyRomusa AI aims to be a friendly and open project where anyone can learn, experiment, and contribute.

## Expected Behavior
- Be respectful and constructive
- Help others learn
- Give useful feedback instead of hate
- Stay on-topic in discussions

## Unacceptable Behavior
- Harassment or toxic behavior
- Spam or irrelevant content
- Disrespect towards contributors

## Enforcement
The maintainer (repository owner) has the right to remove or block content/users that break these rules.

## Final Note
We are here to build cool things together. Keep it chill. 🚀
